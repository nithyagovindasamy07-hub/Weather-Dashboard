# 🌦️ Weather Dashboard

## Project Description
A simple and responsive Weather Dashboard that allows users to check the live weather details of different cities.

## Features
- Search weather by city name
- Display temperature
- Display weather conditions
- Show humidity percentage
- Show wind speed
- Error handling for invalid city names

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- Open-Meteo Weather API

## APIs Used
- Geocoding API: https://geocoding-api.open-meteo.com/
- Weather Forecast API: https://api.open-meteo.com/
